# 📚 Teoria das Estruturas de Dados

Repositório dedicado ao estudo e resolução dos exercícios da disciplina de **Teoria das Estruturas de Dados**.

O objetivo principal é implementar a solução de cada problema em **três linguagens de programação diferentes**, permitindo analisar e comparar os conceitos de baixo nível, orientação a objetos e linguagens de alto nível.

---

## 🛠️ Linguagens Utilizadas

![C](https://img.shields.io/badge/C-00599C?style=for-the-badge&logo=c&logoColor=white)
![Java](https://img.shields.io/badge/Java-ED8B00?style=for-the-badge&logo=openjdk&logoColor=white)
![Python](https://img.shields.io/badge/Python-3776AB?style=for-the-badge&logo=python&logoColor=white)

* **C:** Foco em ponteiros, alocação dinâmica de memória (`malloc`/`free`) e controle explícito.
* **Java:** Foco em Orientação a Objetos, referências de memória e encapsulamento.
* **Python:** Foco em legibilidade, concisão e abstração de tipos.
